# Adjudication of AUDIT.md (lead, before any comparative evaluation)

Date: 2026-11-08. No retrieval method had been run on any benchmark task when these decisions were made.
Edits are applied by `scripts/apply-adjudication.py` (idempotent). Each task records its own adjudication notes in `adjudication`.

## Global decisions
- **G1 accepted: single-bug snapshots (D-017).** Each task is evaluated on pristine upstream + only its own patch (`targets/bench`, branch `task/<id>`). This removes the cross-task masking found by the audit (the JWT-secret bug turning every guarded route into 401, the `UsersRelationalRepository.update` no-op swallowing every user update, the inverted `uniformErrors`, the google default provider). Both REJECTs (`auth_reset_link_reuse_01`, `users_photo_cleared_01`) are reproducible in isolation, so they are kept. All methods still see the identical revision for each task. All 20 snapshots type-check.
- **Relevance policy (applied uniformly):** relevant = root cause + the route→root-cause call path + callees whose behaviour or return value is directly involved. "Where the symptom surfaces" symbols that are not on the cause path, and generic pass-through or padding symbols, are removed. All of the auditor's relevant-set proposals follow this policy and were accepted.
- **G3 overlap relabels accepted** (6 tasks). The dev/test split stays as assigned before the audit (it was stratified on the original labels); it was not re-drawn, to avoid any outcome-dependent choice. The final label distribution is reported in FROZEN.json.
- **G4:** relationships absent from the buggy code were dropped. The removed call in `auth_reset_sessions_01` is recorded under `missing_in_buggy_code`. Controller→service `ROUTES_TO` edges were renamed to `CALLS` (ROUTES_TO is reserved for route→handler). `expected_relationships` are descriptive and are not used by any metric.
- **`test/` stays in the corpus.** The e2e comment the auditor flagged ("reset token is bound to the previous password hash") is genuine upstream code inside a test. Test symbols are never relevant, so a method surfacing it gains no credit. Likewise the upstream comment inside `getForgotSecret` is genuine code that a realistic refactor could leave behind; it was kept, and the task was relabelled overlap high / difficulty medium instead of having its source edited.
- **Descriptions:** under single-bug snapshots the auditor's description rewrites for `auth_social_link_01`, `users_create_provider_01` and `mail_new_email_link_01` became unnecessary (every clause is reproducible), so they were kept verbatim. `users_photo_cleared_01` drops the inaccurate "(photo comes back null)".
